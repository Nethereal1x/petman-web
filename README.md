# Petman — сайт ветеринарної клініки (Львів)

Статичний сайт на Astro. Замінює односторінковий сайт на конструкторі й закриває пункти аудиту від 16.11.2026:
окремі сторінки послуг, прайс із «грн» і датою, форма зі згодою, політика конфіденційності, клікабельний
телефон, розмітка `VeterinaryCare`, легка сторінка.

## Запуск

```bash
npm install
npm run dev        # розробка, http://localhost:4321
npm run build      # збірка в dist/
npm run preview    # перегляд зібраного сайту
```

Потрібен Node 20+. Результат збірки — звичайні статичні файли, їх можна викласти на будь-який хостинг.

## Де що міняти

| Що | Файл |
| --- | --- |
| Телефон, адреса, графік, соцмережі, реквізити, дата прайсу, оцінка Google | `src/data/site.ts` |
| Послуги, ціни, тексти сторінок послуг, питання-відповіді | `src/data/services.ts` |
| Команда і відгуки | `src/data/team.ts` |
| Розмітка schema.org | `src/data/schema.ts` |
| Кольори, шрифти, кнопки, шапка, футер | `src/styles/global.css` |
| Анімації та вся поведінка | `src/scripts/app.ts` |

Нова послуга = новий об'єкт у `services.ts`. Сторінка, рядок у прайсі, пункт у футері, sitemap і розмітка
з'являться самі.

### Зображення

Оригінали лежать в `assets-src/`. Після заміни чи додавання фото:

```bash
node scripts/build-images.mjs
```

Скрипт робить AVIF і WebP у кількох ширинах у `public/img/` і оновлює `src/data/images.json`.

### Форма запису

Форма надсилає JSON методом POST на адресу зі змінної `PUBLIC_FORM_ENDPOINT` (файл `.env`):

```
PUBLIC_FORM_ENDPOINT=https://…
```

Поля: `name`, `phone` (+380…), `pet`, `reason`, `message`, `consent`, `consentAt`, `page`.
Поки змінна порожня, форма чесно каже відвідувачу, що онлайн-запис ще не під'єднано, і пропонує подзвонити.

## Що має надати клініка перед запуском

Порожні реквізити на сайті підсвічені помаранчевими плашками, пропустити їх неможливо.

1. **Реквізити**: ПІБ ФОП або назва юрособи, РНОКПП/ЄДРПОУ, дані ліцензії на ветеринарну практику
   (`site.legal`). Показуються у футері, на «Контактах» і в політиці конфіденційності.
2. **Як заклад оформлено в документах**: «клініка» чи «кабінет». Зараз усюди «ветеринарна клініка».
3. **Поштовий індекс**: на старому сайті 79029, у картці Google 79000, за картою OSM 79057 (стоїть він).
4. **Строк акції на Чекап 8+**: `promo.until` у `services.ts`. Без дати сайт показує акційну ціну з
   приміткою «строк уточнюйте в адміністратора».
5. **Ціни на вакцинацію і грумінг**, перелік послуг грумінгу, що продає зоомагазин. Зараз на цих сторінках
   «ціну назвемо телефоном».
6. **Тексти про підготовку й перебіг процедур** на сторінках послуг написані загально, з прайсу і старого
   сайту. Їх має перечитати лікар.
7. **Політика конфіденційності**: це робочий шаблон під закон «Про захист персональних даних», його варто
   показати юристу. Строк зберігання заявок (12 місяців) — припущення.
8. **Фото**: собака на першому екрані, кіт і ретривер — вільний сток (Unsplash), фон вирізано. Портрети
   команди і фото клініки взято зі старого сайту. Власна зйомка пацієнтів зробить сайт сильнішим.
9. **Відгуки** перенесено зі старого сайту. Оцінку 4,8 і кількість 82 оновлювати вручну в `site.rating`
   разом із датою.

## Після викладки

- Додати сайт у Google Search Console і надіслати `https://petman.com.ua/sitemap-index.xml`.
- Перевірити сторінки в Rich Results Test (типи `VeterinaryCare`, `Service`, `FAQPage`, `BreadcrumbList`).
- Налаштувати на хостингу сторінку помилки на `/404.html`.
- Якщо старі адреси конструктора відрізняються, поставити 301-редиректи на нові.
